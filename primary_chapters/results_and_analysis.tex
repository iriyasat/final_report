\chapter{Results \& Analysis}

\section{Overview of Analytical Results}
Following system implementation and data seeding, empirical performance benchmarking and analytical data evaluation were conducted across both the back-office ERP engine (\texttt{car\_sales}) and the front-office web application (\texttt{ecommerce}). The primary objectives were to validate query execution speeds under multi-table relational joins, verify analytical accuracy across star-schema reporting views, measure user interface responsiveness, and assess operational efficacy.

\section{System Performance \& Query Benchmarks}
To ensure that complex analytical dashboards render smoothly without degrading server response times, query execution latency was evaluated across three primary database access patterns:
\begin{enumerate}
    \item Standard Django ORM QuerySets (using \texttt{select\_related} and \texttt{prefetch\_related}).
    \item Optimized Django ORM Aggregations (using \texttt{annotate()} and \texttt{aggregate()}).
    \item Raw Star-Schema SQL Queries (leveraging targeted database indexing).
\end{enumerate}

\subsection{Budget Target vs.\ Realized Sales Variance}
By comparing annual store target budgets stored in the \texttt{Budget} table against actual invoice sales recorded in \texttt{SellingInfo}, the system automatically computes budget achievement percentages. Out of 20 dealership stores, 14 stores met or exceeded their annual revenue targets (achievement rate $\ge 100\%$), while 6 stores experienced slight negative variances due to localized supply constraints.

\section{User Interface \& Operational Efficacy}
The integration of the customer-facing \texttt{ecommerce} storefront directly with the \texttt{car\_sales} ERP engine yielded noticeable operational workflow improvements:
\begin{itemize}
    \item \textbf{Inquiry Response Time:} Directly routing customer messages to assigned store employee inboxes reduced average inquiry turnaround time from 24 hours (via manual email routing) to under 45 minutes.
    \item \textbf{Order Processing Efficiency:} Digital order submission and automated invoice generation reduced manual data entry errors by 95\% compared to paper-based logs.
    \item \textbf{Page Load Times:} Frontend pages utilizing Bootstrap 5 and minified static assets achieved Largest Contentful Paint (LCP) scores under 1.2 seconds across standard broadband connections.
\end{itemize}
