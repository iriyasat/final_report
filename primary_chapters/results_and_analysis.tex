\chapter{Results \& Analysis}

\section{Overview of System Results}
Following the implementation of the dual-application architecture, the completed platform was evaluated across its administrative back-office ERP engine (\texttt{car\_sales}) and its public customer storefront (\texttt{ecommerce}). Rather than evaluating theoretical models, assessment was conducted using the deployed web user interfaces operating over live dealership data.

The evaluation demonstrates the operational workflow across five core functional areas:
\begin{enumerate}
    \item \textbf{Executive Dealership Dashboard:} Real-time consolidation of enterprise sales metrics, order approvals, and sales trend tracking.
    \item \textbf{Customer Vehicle Catalog:} Dynamic inventory exploration featuring asynchronous multi-parameter filtering and price range navigation.
    \item \textbf{Vehicle Detail \& Reservation Portal:} Transparent pricing disclosures based on MMR valuations, digital reservation workflows, and store inquiry dispatching.
    \item \textbf{Store Sales Analytical Reporting:} Specialized administrative reporting powered by hand-crafted star-schema SQL queries and REST API endpoints.
    \item \textbf{Sales Quota \& Budget Variance Tracking:} Employee-level performance monitoring comparing monthly volume and revenue targets against realized sales.
    \item \textbf{Store CRM \& Customer Inquiry Management:} Integrated showroom messaging enabling direct customer-to-salesperson communication.
\end{enumerate}

\section{Security \& Role-Based Access Summary}
To ensure organizational data security across the user tiers shown in the interfaces, access boundaries are enforced through Django's authentication and custom permission middlewares:
\begin{itemize}
    \item \textbf{Retail Customers:} Restricted to public catalog browsing, personal profile updates, and submitting checkout orders or inquiries.
    \item \textbf{Sales Representatives (Level 9):} Scoped to branch inventory access, managing their assigned customer inquiries, and logging completed sales.
    \item \textbf{Branch Managers (Levels 6 \& 8):} Authorized to review and approve customer holding orders, access store analytical reports, and assign test-drive hosts.
    \item \textbf{Executive Administrators (Levels 1--4):} Granted global visibility across all 173 branches, employee budget allocations, and system configuration controls.
\end{itemize}
